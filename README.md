# 划词翻译(Edge 扩展)

选中网页或 PDF 里的文字即可翻译,完全免费,不需要任何 API Key。

## 安装(开发者模式)

1. 在 Edge 地址栏打开 `edge://extensions`
2. 打开「开发人员模式」
3. 点「加载解压缩的扩展」,选择本文件夹(含 `manifest.json` 的这一层)

装好后刷新已打开的网页即可使用。

## 用法

- **划词**:选中文字 → 旁边出现蓝色小图标 → 点击查看译文
- **右键**:选中文字 → 右键「翻译“…”」
- **快捷键**:选中文字后按 `Alt+T`(可在 `edge://extensions/shortcuts` 修改)
- **手动输入**:点工具栏的扩展图标,在输入框里翻译
- 译文卡片上可以朗读原文/译文、复制译文,按 `Esc` 或点别处关闭

## 翻译 PDF

Edge 自带的 PDF 阅读器不允许扩展注入脚本,所以本扩展内置了 pdf.js 阅读器(`pdfjs/` 目录):

- 打开网址以 `.pdf` 结尾的 PDF(网页或本地文件)时,会自动跳转到内置阅读器,在里面划词翻译
- 网址不以 `.pdf` 结尾的 PDF(例如 arXiv 的 `arxiv.org/pdf/xxxx`):点工具栏图标 →「用阅读器打开当前页面的 PDF」
- 打开**本地** PDF(`file:///…`)需要:`edge://extensions` → 本扩展「详细信息」→ 开启「允许访问文件网址」
- 不想自动接管 PDF:工具栏图标里关掉「用本扩展的阅读器打开 PDF」
- 扫描件/图片型 PDF 没有文字层,选不中文字,翻译不了

`pdfjs/` 是 Mozilla pdf.js 6.4.299 官方发布包(Apache-2.0,见 `pdfjs/LICENSE`),相对原版只改了三处:
`web/viewer.mjs` 放开「文件必须与阅读器同源」的检查;`web/viewer.html` 的 CSP 增加 `file:` 与内联样式,
并在页尾加载 `content.js`。

## 设置(点工具栏图标)

- 目标语言:简体/繁体中文、英、日、韩、法、德、西、葡、意、俄、阿、越、泰
- 优先翻译源:Google 翻译(默认)/ MyMemory,一个不可用时自动切换到另一个
- 划词后:显示小图标 / 直接弹出翻译 / 不自动触发

原文语言和目标语言相同时会自动反向翻译(中文 → 英文,其他语言 → 中文)。

## 说明

- 翻译源是 Google 翻译的免费网页接口和 MyMemory 免费接口,都是非官方/有限额的服务,
  适合日常阅读,不保证长期稳定。短时间内大量请求时 Google 可能返回 429 限流,此时会自动改用 MyMemory;
  MyMemory 匿名每天约 5000 字符的额度。
- 单次最多翻译 5000 字。
- `edge://` 页面和扩展商店页面不允许扩展注入脚本,这些页面里划词无效。
